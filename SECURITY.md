# Security policy

Do not open a public issue for a suspected vulnerability, exposed credential, private endpoint, or personal data. Use GitHub's private vulnerability reporting or security advisory flow for this repository.

The current deployment is a substantive static diagnostics lab that remains noindex before SEO launch. Its tools process supplied evidence locally in the browser. Any future network fetcher, authentication flow, API, upload, user data, billing, or destructive action requires a dedicated security review before release.
